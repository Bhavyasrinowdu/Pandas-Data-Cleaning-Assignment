# Pandas Data Cleaning and Visualization

## Overview

This project demonstrates data cleaning and basic data visualization using Python, Pandas, Matplotlib, and Seaborn.

## Dataset

The dataset contains exercise-related information such as:

* Duration
* Date
* Pulse
* Maxpulse
* Calories

## Tasks Performed

* Loaded a CSV dataset using Pandas
* Inspected the dataset
* Identified missing values
* Handled missing values
* Converted the Date column to datetime format
* Filtered rows based on Duration
* Created a new `Pulse_Difference` column
* Generated basic statistical information
* Created visualizations using Matplotlib
* Created visualizations using Seaborn
* Saved the cleaned dataset as `cleaned_data.csv`

## Technologies Used

* Python
* Pandas
* Matplotlib
* Seaborn

- `data.csv` — Original dataset
